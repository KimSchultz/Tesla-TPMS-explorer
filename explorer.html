Tire sensor explorer

Watch and read the Bluetooth tire pressure sensors in a Tesla from Chrome on Android. Read-only: this page never writes to a sensor.

Before you scan
  1. Stand next to one wheel and pick its sensor. Chrome’s picker shows each sensor’s address; original and Autel sensors start with BC:6A:29 or E4:FA:5B, and Service Mode › Chassis › TPMS shows which address sits on which wheel. Type the wheel or address into the label field so the log records which sensor each reading came from.
  2. Pick one sensor. Its broadcasts only say “I’m here” (Tesla company ID 0x022B, payload 01 FE 03 while parked); the measurements are read over a connection, like the car does.
  3. Connect, then tap Subscribe on “Tesla tyre data”. The sensor sends pressure and temperature straight away, then a heartbeat every four minutes while it stands still. It accepts one connection at a time, so this only works while the car isn’t connected to it, and the car can’t hear it until you disconnect.
  4. Tesla’s protocol has a battery voltage field, but it hasn’t been seen from a sensor yet; it probably only comes while the sensor is awake from driving. Each message lists every field it contains, named where Tesla’s protocol has a name. Untick “Only show Tesla tyre sensors” right after a drive to find an awake sensor.
