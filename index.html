Tips
  • The picker only lists Tesla tyre sensors that are parked and not connected to the car. If the car is awake and connected to a sensor, lock it and walk away for a minute.
  • The picker shows each sensor’s address. Service Mode › Chassis › TPMS on the car shows which address is on which wheel.
  • If a wheel’s sensor never appears in the list, tap “Not in list” on that wheel. That’s the usual sign of a dead sensor battery.
  • Battery level isn’t known to be sent by the sensor. If a sensor sends anything beyond pressure and temperature, it shows up highlighted as extra data.
  • Some clone sensors always report 29 °C. If a wheel never changes from 29 °C, the temperature isn’t real.
  • Readings stay in this browser on this phone. Clearing Chrome’s site data deletes them, so download a copy if you want to keep it.
  • Need raw services and broadcasts? Use the advanced explorer.
